# 📱 SMS Dashboard - Telegram Mini App

A complete Telegram Mini App dashboard for managing multiple Firebase-connected devices with SMS capabilities.

## 🚀 Features

- 🔐 **Access Key Authentication** - Secure login with admin-generated keys
- 📊 **Live Dashboard** - Real-time device status, online/offline tracking
- 📱 **Device Management** - View all devices with battery, signal, and status
- 💬 **SMS Management** - View live SMS feed with auto-refresh (latest 100 messages)
- ✉️ **Send SMS** - Send messages from specific SIMs
- 🔥 **Multi-Firebase Support** - Connect multiple Firebase instances
- ⚙️ **Admin Panel** - Generate access keys, manage Firebase sources
- 🎨 **Telegram Native** - Seamless integration with Telegram theme
